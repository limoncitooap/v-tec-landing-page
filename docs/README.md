# V-TEC — Asistente de Pre-selección Vehicular (Taggle Inc.)

Landing Page responsive y herramienta interactiva de diagnóstico vehicular para el mercado de segunda mano en el Perú. Desarrollada para el curso **1ASI0784 - HCI for UX Design (UPC)**.

## Propósito
Reducir la parálisis de decisión y la asimetría de información en compradores primerizos, de recambio/upgrade y trabajadores operativos, traduciendo prioridades cotidianas y presupuesto real en soles en recomendaciones técnicas concretas con soporte verificado en Perú[cite: 9].

## Tecnologías utilizadas
- HTML5 semántico y accesible (WCAG 2.2)[cite: 17, 27]
- CSS3 (Variables CSS, Grid, Flexbox, Media Queries responsive)[cite: 17, 18]
- JavaScript puro (Vanilla JS) con dataset local del mercado peruano y persistencia en `localStorage`[cite: 9, 17]

## Estructura del repositorio
- `assets/`: recursos visuales, íconos, fuentes y multimedia[cite: 19].
- `css/styles.css`: hoja de estilos basada en la guía de estilos V-TEC (regla 60-30-10 y tipografía Manrope)[cite: 9, 19].
- `js/main.js`: motor algorítmico de compatibilidad, validaciones, comparador y persistencia[cite: 19].
- `pages/index.html`: página principal de la aplicación[cite: 19].
- `docs/README.md`: documentación del proyecto[cite: 19].
